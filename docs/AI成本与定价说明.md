# 家游汇 AI 成本与定价说明

核查日期：2026-11-04

## 一、模型成本

DeepSeek 官方当前对 `deepseek-flash` 的价格为：

- 输入缓存未命中：非峰值每百万 token $0.15，峰值 $0.30
- 输入缓存命中：非峰值每百万 token $0.003，峰值 $0.006
- 输出：非峰值每百万 token $0.60，峰值 $1.20

官方给出的中文 token 换算约为每 1 个汉字 0.6 token。

一次典型 3 天家庭行程包含多轮工具选择、RAG 依据回填、12306 与天气结果和最终 JSON：

| 场景 | 输入 token | 输出 token | 峰值模型成本 | 非峰值模型成本 |
| --- | ---: | ---: | ---: | ---: |
| 简单行程 | 约 12,000 | 约 3,000 | 约 $0.0072（¥0.05） | 约 $0.0036（¥0.026） |
| 典型行程 | 约 20,000 | 约 4,500 | 约 $0.0114（¥0.08） | 约 $0.0057（¥0.04） |
| 复杂行程或重试 | 约 40,000 | 约 10,000 | 约 $0.024（¥0.17） | 约 $0.012（¥0.085） |

汇率按约 1 USD = 7.1 CNY 估算。考虑重试、服务器、监控、支付手续费和客服余量后，建议把完整行程的综合成本预算设为 **¥0.12–0.25/次**。轻量修改或问答通常低于 **¥0.03/次**。
