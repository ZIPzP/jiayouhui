# 家游汇 · 评委快速上手（3 分钟走完主链路）

> 面向评审老师。不需要安装任何东西，直接看线上演示；想在本地跑也只需双击 `启动.bat`。
> 在线演示：<https://familytravelhublz.top>

---

## 一、开始之前

| 项目 | 说明 |
| --- | --- |
| 推荐浏览器 | Chrome / Edge 最新版（地图页需要加载高德 JS API） |
| 不需要登录 | 站点公开访问，没有账号体系 |
| AI 是否需要 Key | **基础规划不需要**。未解锁 AI 时，内置规则引擎、本地 RAG 依据和真实车次仍可使用；模型自主工具选择与截图识别需要 Key |
| 网络要求 | 行程页会实时查询 12306 车次与天气，需要正常联网；这两个数据源失败时会明确提示并降级，不会白屏 |

## 二、主链路（约 3 分钟）

| # | 点什么 | 应该看到什么 |
| --- | --- | --- |
| 1 | 打开 <https://familytravelhublz.top> | 首页：精选家庭目的地、快速规划入口 |
| 2 | 点导航「目的地」→ 筛选「老人友好」→ 点开任一张卡片 | 目的地详情弹窗：亮点、当地美食、适老提示、天气；可打开实景图集 |
| 3 | 点导航「行程规划」 | 家庭约束表单：出发地、目的地、去返日期、同行人（成人/老人/儿童）、交通、节奏、预算、忌口、兴趣、其他需求 |
| 4 | 填「上海 → 杭州」，选 3 天，2 成人 + 1 老人 + 1 儿童，点「生成行程」 | 后台任务轮询后出逐日行程：每天分上午/午餐/下午/晚餐，含交通、住宿、人均花费；下方是所选日期天气与 12306 真实车次票价 |
| 5 | 点结果区的「进入地图工作台」 | 三栏工作台：左侧每日日程、中间按天着色的路线与标记、右侧地点信息 |
| 6 | 点导航「出行清单」→ 选「中期 3–5 天」→ 生成 | 与最近一次行程关联的打包清单，分组可勾选，含老人常用药与儿童用品 |
| 7 | 右上角「⚙️ 设置」 | 可切换**中英双语**与**长辈模式**（大字号、高对比、大按钮、语音朗读） |

> 想验证 AI 路径：在「⚙️ 设置 → AI 设置」里填入自己的 OpenAI 兼容 Key（只存在当前浏览器），
> 或向团队索取评审专用邀请码解锁服务端额度。**两种方式都不影响其他评审体验。**

建议额外验证三条新增能力：

| 能力 | 操作 | 预期 |
| --- | --- | --- |
| RAG 依据 | 生成杭州行程后，打开右侧「依据」 | 显示杭州景点、适老、餐饮或打包规则来源，并可点击跳转 |
| 流式对话 | 在行程管家切换到「解释规划」，问“为什么第 2 天这样安排？” | 先显示检索/推理/生成状态，再逐字回答，末尾附本次依据 |
| 截图导入 | 在补充要求区点「选择截图」上传攻略图片 | 识别结果只预填表单，不自动生成；无 Key 时给出明确提示 |

## 三、这个作品解决了什么

家庭出行的难点不是找景点，而是「全家人能不能舒服地走完每一天」：老人走不动、孩子要午睡、有人忌口、还得赶得上高铁。

家游汇把这些约束做成一条可执行的链路：**家庭约束输入 → 逐日行程 → 真实车次与天气 → 地图路线 → 出行清单**。

三条值得留意的工程取舍：

1. **车次与票价不交给模型发挥**：12306 结果先查成结构化对象，作为「不可改写事实块」注入提示词，同时在响应里单独保留 `realTrains`，页面上显示的车次永远来自这里。
2. **结构化输出加清洗**：请求带 `response_format: json_object`，服务端再用 `extractJson` 剥掉可能夹带的 Markdown 围栏，字段缺失直接拒收，不把半截 JSON 渲染到页面上。
3. **可执行的降级**：没有 Key、超时、返回非 JSON 时，规则引擎接管并生成完整行程；本地检索与真实车次不依赖模型生成。
4. **可审计的 AI 工作流**：模型通过白名单工具选择检索、12306 和天气，页面保留工具轨迹；图片来源与工具参数都有边界校验。

## 四、常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 地图区域空白 | 高德 JS API 未加载（网络或浏览器拦截）。刷新重试；文字行程与清单不受影响 |
| 天气只显示 15 天 | 数据源只提供未来 15 天；超出会明确提示，不会假装有数据 |
| 提示「所选时段暂无车次，自动推荐上午车次」 | 这是**防编造**设计：该时段确实没有直达车，系统给提示而不是编一个班次 |
| 生成要等十几秒 | 一次生成要串行查去程/返程车次与票价，再计算行程。已做车次缓存与并发查询，首次会慢一些 |
| 中文正常、切英文后有少量中文 | 英文词典按中文原文匹配，偶有新文案未收录；属于本次已记录待优化的已知限制 |

## 五、本地运行（可选）

项目零运行时依赖，不需要 `npm install`，只需要 Node.js 18+：

```bash
git clone https://github.com/ZIPzP/jiayouhui.git
cd jiayouhui
node server.js
# 打开 http://localhost:3000
```

Windows 可直接双击仓库根目录的 `启动.bat`，它会检查 Node 版本、提示端口占用并自动打开浏览器。
