# 字体与第三方组件许可

核查日期：2026-11-04

## 字体

- 项目没有打包 `.woff`、`.woff2`、`.ttf`、`.otf` 或 `.eot` 字体文件，不向访问者分发字体二进制。
- 页面字体使用 `PingFang SC`、`Microsoft YaHei`、`Segoe UI` 等操作系统自带字体作为回退。字体只在用户本机渲染，相关使用受操作系统许可约束，不构成项目再分发。
- 未引用的 `Noto Sans SC` 名称已从公共样式和孤立实验页中移除。

## 第三方 JavaScript

| 组件 | 版本 | 用途 | 许可 |

| html2canvas | 1.4.1 | 将行程或清单导出为图片 | MIT |
| SortableJS | 1.15.6 | 行程卡片拖拽排序 | MIT |
