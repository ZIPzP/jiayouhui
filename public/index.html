📖 关于家游汇

🤖 AI 大模型

接入 OpenAI 兼容接口（可配置 DeepSeek / 通义 / Moonshot 等），根据「目的地 + 出行时段 + 同行人」生成个性化打包清单与攻略；未配置 Key 时自动使用内置规则引擎。

📊 平台热门数据

内置「数据采集器」：默认使用本地趋势库，可通过 config.json 接入官方开放接口或自建数据服务。为遵守平台条款与版权，不直接抓取用户页面内容。

👴 老年人模式

一键切换大字体、高对比、大按钮，并支持语音朗读目的地介绍，让长辈看得清、听得懂。

📷 真实地点照片

背景与景点图片来自 Unsplash 免费授权真实旅游摄影；可在 data/destinations.json 中替换为你自有的授权照片。

🤖 AI 大模型设置

推荐 DeepSeek：点下方「🚀 DeepSeek」一键填入接口与模型，再把你的 API Key 粘贴到 Key 输入框。Key 仅保存在你的浏览器本地，不会上传。
