📖 关于家游汇

🐱 AI 大模型

接入 DeepSeek 等大模型，根据「目的地 + 出行时段 + 同行人 + 忌食/预算」生成个性化行程与打包清单；未配置 Key 时自动使用内置规则引擎。

📍 自定义目的地

不局限于内置城市列表：在「行程规划」中输入任意城市，AI 照样为你规划。

👴 老年人模式

一键切换大字体、高对比、大按钮，并支持语音朗读，让长辈看得清、听得懂。

🔒 隐私安全

API Key 可内置到服务器本地配置（不入 git），支持访问口令门禁，公网部署时保护你的配额。
